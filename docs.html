Getting started

  1. Create a TubePilot account using the sign-in options shown in the app.
  2. Connect the YouTube channel you own or are authorized to manage, using the app's Google authorization flow.
  3. Explore AI ideas, titles, descriptions, hashtags and SEO tools.
  4. Prepare your video, upload it and choose a publishing schedule where available.
  5. Review published video performance using analytics features.

Diamonds and usage

TubePilot uses a Diamond/credit balance for eligible paid usage. The current balance, package options and feature entitlements are displayed in the live app. Confirm the latest package details in the Diamond Store before purchase.

Account and support

For account help, billing questions, upload issues or data deletion requests, visit Contact or Account & Data Deletion.

YouTube permissions

Connecting a YouTube channel requires the relevant Google authorization and permissions. The exact features available depend on granted scopes, YouTube API access and platform requirements.
